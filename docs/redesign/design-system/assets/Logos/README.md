`logo.svg` is the original HumanSoul mark (480×130, 3.7:1). It is drawn in dark ink (`#27201b`) with one gray and one white detail, and is shown with `<img>`, so it does not inherit the theme color.

- Use it only on `background` and `card` in the light theme.
- On the dark theme use the `Logo` component, which inherits `foreground`.
- Minimum width: 96px. Leave a margin around it equal to the height of the "H".
