Una entrada del diario con fecha, favorita, foto, texto y etiquetas.

## Qué aporta quien lo usa
`date`, `favorite`, `onToggleFavorite`, `photo`, `photoAlt`, `tags`, hijos como texto.

## Guía
El corazón es un botón con `aria-pressed`. La misma tarjeta se usa en Reflexiones y en Favoritas. El texto conserva los saltos de línea.
